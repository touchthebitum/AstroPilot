NightMerit · Assistant de sauvegarde et de reprise

Retrouver mes données

Fermez d’abord NightMerit et ses outils automatiques utilisant cette copie. Cet assistant vous guide pour sauvegarder vos essais ou les reprendre dans une nouvelle copie.

Lecture de cette copie…

Sauvegarder mes essais

Conservez vos réglages, projets, sessions, observations et comparaisons dans un fichier à garder pour la prochaine version.

Dans les kits privés : retrouvez le fichier dans SAUVEGARDES, sous DONNEES-BETA sur Mac ou sous RESULTATS sur votre PC Windows. Avec une autre installation, vérifiez les téléchargements du navigateur.

Cette sauvegarde contient vos données personnelles. Elle ne contient pas le programme et ne synchronise pas vos appareils.

Reprendre mes essais dans cette copie

Choisissez une sauvegarde NightMerit créée par cet assistant. Son contenu sera vérifié avant toute reprise. Votre ancienne copie sera conservée.

Sur votre PC, placez d’abord le fichier de sauvegarde dans le dossier de ce nouveau kit, avant de lancer Windows Sandbox. Choisissez-le ensuite dans C:\NightMeritInput. Si le fichier manque, fermez Sandbox, placez-le dans le dossier du kit, puis rouvrez cet assistant.

Reprendre ma sauvegarde dans une nouvelle copie

  1. Conservez ce dossier et fermez cet assistant. Sur Windows, fermez Windows Sandbox.
  2. Extrayez le kit dans un nouveau dossier. Sur Windows, placez-y votre fichier de sauvegarde.
  3. Ouvrez directement GERER-MES-DONNEES.command sur Mac ou GERER-MES-DONNEES.cmd sur Windows, avant de lancer l’application.

Vous pourrez alors choisir votre sauvegarde et confirmer la reprise de vos essais.

Pour continuer ensuite

Sur Mac, fermez sa fenêtre de navigateur. Sur Windows, fermez Windows Sandbox. Ouvrez ensuite le lanceur habituel de cette même copie. Retrouvez votre projet dans « Mes projets » et vos relevés dans « Mes observations ».

Les sauvegardes sont indépendantes : une nouvelle saisie sur le Mac ne modifie pas automatiquement la copie Windows. Aucun dossier contenant déjà des données n’est remplacé ni fusionné.
