Sauvegarder mes essais

Conservez vos réglages, projets, séances photo, observations et comparaisons dans un fichier à garder pour la prochaine version.

Retrouvez le fichier ZIP dans les téléchargements de votre navigateur. Vérifiez sa présence avant de fermer cette copie.

Cette sauvegarde contient vos données personnelles. Elle ne contient pas le programme et ne synchronise pas vos appareils.

Reprendre mes essais dans cette copie

Choisissez une sauvegarde NightMerit créée par cet assistant. Son contenu sera vérifié avant toute reprise. Votre ancienne copie sera conservée.

Sélectionnez votre fichier ZIP là où vous l’avez enregistré, par exemple dans Téléchargements. Aucun déplacement préalable dans le kit n’est nécessaire.

Ces données ne sont pas encore reprises. Vérifiez le contenu ci-dessus, puis cliquez sur le bouton ci-dessous.

Si l’ouverture automatique échoue, fermez cet assistant avec Ctrl+C dans sa fenêtre de commande, puis ouvrez DEMARRER-DEMO.cmd dans ce même dossier.

J’ai déjà une sauvegarde

Reprendre ma sauvegarde dans une nouvelle copie

  1. Conservez ce dossier. Fermez cet assistant avec Ctrl+C dans sa fenêtre de commande.
  2. Extrayez le kit dans un nouveau dossier au nom court, par exemple NM-Restauration dans votre dossier utilisateur.
  3. Ouvrez directement GERER-MES-DONNEES.command sur Mac ou GERER-MES-DONNEES.cmd sur Windows, avant de lancer l’application.

Vous pourrez alors choisir votre sauvegarde et confirmer la reprise de vos essais.

Ouvrir cette copie

Fermez cet assistant avec Ctrl+C dans sa fenêtre de commande. Ouvrez ensuite le lanceur habituel de cette même copie. Retrouvez votre projet dans « Mes projets » et vos relevés dans « Mes observations ».

Les sauvegardes sont indépendantes : une nouvelle saisie sur le Mac ne modifie pas automatiquement la copie Windows. Aucun dossier contenant déjà des données n’est remplacé ni fusionné.
