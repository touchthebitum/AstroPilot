# AstroPilot Domain Model

## Objectif

Le Domain Model décrit les concepts métier manipulés par AstroPilot.

Chaque concept représente une réalité de l'astrophotographie.

Le code devra toujours suivre ce modèle.

Le modèle métier est prioritaire sur l'implémentation.
