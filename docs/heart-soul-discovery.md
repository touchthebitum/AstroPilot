The operational selection adds two whole H II regions: Sh2-190 (Cœur) and Sh2-199 (Âme). Production fields and intents are respectively `sh2-190` / `sh2-190_ha` and `sh2-199` / `sh2-199_ha`. Existing portfolio identities `IC1805` and `IC1848` remain unchanged. These identifiers are not a statement that the embedded stellar clusters have the same extents as their surrounding nebulae.

Sharpless CDS VII/20 lists maximum diameters 150′ (190) and 120′ (199), respectively. Those selected values are already in the studied imaging catalogue. The existing planning centres 38.5°, +61.4° and 42.825°, +60.408333° are independently declared in production geometry. No coordinates from the B1900/B1950 Sharpless catalogue or the photo are imported. No historical catalogue sizes, coordinates or saved keys are rewritten.

The material gate still requires a nominal full-sensor framing fit with a 10% margin, a confirmed exact Baader Hα 6.5nm Highspeed filter and documented working focal ratio. Visibility, productive time and current weather evidence are still assessed. Being supported does not guarantee a place in the three highest-ranked suggestions, nor a useful mission in a particular season.

## Existing projects and validation

For catalogue aliases `Heart` and `Soul`, discovery returns the exact existing key separately from the canonical candidate identity. The UI opens that saved project rather than creating or migrating one. If several saved keys identify the same canonical region, the candidate is omitted rather than guessing or combining progress.

Tests exercise actual forecast ranking in a synthetic early-evening winter window, each explicit configuration/decision/acceptance path, refusal of the other region’s intent, zero automatic progress or execution, preservation of saved aliases and actual JavaScript licence/alias rendering. Existing Orion and general discovery tests remain applicable. This is software validation, not a real observing report or native-kit validation. Existing private beta kits stay unchanged.
